# Astro design sketch

`mass_grid.astro` is a syntax illustration for [Astro](https://github.com/astrolang/astro) 0.1.15a, an experimental programming language. Its compiler currently produces an AST and does not support a complete runnable application. This sketch is not part of the calculation pipeline. `campaign.json` is a separate runnable scheduler input; its example isotope values are illustrative, not a calibrated data set.
