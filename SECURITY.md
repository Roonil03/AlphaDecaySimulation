# Security policy

## Report a vulnerability

Please do not include vulnerability details, exploit instructions or secrets in an issue, pull request or other public discussion. If you already have a private contact with the repository maintainer, use it to request a confidential reporting channel and confirm the recipient before sharing details.

Otherwise, use the [owner's contact page](https://roonil03.github.io/#/contact) to find the listed Discord community, or open a repository issue asking how to contact the owner privately. In that initial request, give no vulnerability details. Once the owner confirms a private channel and recipient, share the report there.

A useful private report identifies the affected version or commit, the operating system, the impact, and the steps and inputs needed to reproduce the problem. Include any relevant logs with credentials and personal data removed. Please coordinate disclosure with the maintainer so there is time to investigate and prepare a fix.
